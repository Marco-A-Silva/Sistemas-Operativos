# Sistemas Operativos

## Descripción
Este repositorio documenta mi formación y prácticas en la arquitectura y funcionamiento de los Sistemas Operativos. Aquí se encuentran implementaciones y ejercicios orientados a entender cómo interactúa el software con el hardware.

## Conceptos Clave
* **Gestión de Procesos:** Planificación, concurrencia, hilos y sincronización.
* **Gestión de Memoria:** Paginación, segmentación y manejo de memoria virtual.
* **Sistemas de Archivos:** Organización, estructuras de directorios y acceso a disco.
* **Llamadas al Sistema (Syscalls):** Interfaz entre aplicaciones y el núcleo (kernel).
